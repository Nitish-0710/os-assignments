# Operating Systems Assignments

This repository contains the **Operating Systems laboratory assignments** for the academic year **AY 2026–27**.

The assignments are designed to provide practical understanding of core Operating System concepts through implementation in **C, C++, Shell scripting, AWK, and POSIX system programming**.

The repository also includes a set of **AI-enabled Operating Systems assignments** that explore how Artificial Intelligence and Machine Learning can be applied to traditional OS problems.

The primary goal of this repository is not only to complete the laboratory assignments but also to develop a practical understanding of **Operating System internals and system-level programming**.

Through these assignments, the following concepts will be explored:

* How processes are created and managed
* How processes communicate
* How threads enable parallel execution
* How CPU scheduling algorithms work
* How deadlocks occur and can be avoided
* How memory is allocated
* How virtual memory and page replacement work
* How Linux IPC mechanisms operate
* How AI can be applied to traditional Operating System problems
